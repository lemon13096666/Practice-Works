# Practice-Works

Учебный репозиторий с практическими проектами, созданными в Visual Studio.

## Содержимое

- `VisualStudioProjects/` — проекты для практических работ.
- `vs.html` — учебная веб-страница.

Для работы клонируйте репозиторий и откройте нужное решение Visual Studio.

## Практика Git

Файл обновлён в локальной ветке, зафиксирован коммитом и отправлен в удалённый репозиторий.
